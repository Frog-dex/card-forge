# sample-art/

Drop line-art cutout PNGs here (transparent background, named `card-NN.png`) to feed
the deck editor and build scripts. The original Spirit Strikers drawings are not
bundled with this repo; point the `CUT` constant at the top of `deck-editor.html`
(and `ARTSRC` in `scripts/plan_cards.py`) at this directory to use your own art.
